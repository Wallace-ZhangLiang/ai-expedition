# AI Expedition —— 我的 AI 学习与实践知识库

> 一个公开的 AI 学习与实战记录库：概念笔记、源码剖析、实验复现、工具代码。
> 范围不限于编译器或昇腾，覆盖 AI 的方方面面，持续更新。

## 内容分类

| 目录 | 内容 |
|---|---|
| [`knowledge/`](knowledge/) | 概念性知识笔记，按主题分：编译器 / 大模型 / ML 基础 / CV / NLP / 多模态 |
| [`deep-dives/`](deep-dives/) | 深入剖析、源码走读（一篇一个子目录：md + 代码） |
| [`experiments/`](experiments/) | 实验与复现（一个实验一个子目录：操作手册 + 分析 + 解决方案 + 复现脚本） |
| [`tools/`](tools/) | 可复用的小工具 / 脚本 |
| [`practice/`](practice/) | 入门练习代码 |
| [`roadmap/`](roadmap/) | 学习路线图（给想一起学的读者） |
| [`resources/`](resources/) | 书单 / 论文 / 优质链接 |

## 命名与写作约定

- 笔记命名：`主题-标题.md`，如 `Triton原理入门-块思维与原语.md`
- 每个实验子目录固定包含：`README.md`（一句话概览）+ `分析.md` + 复现脚本，必要时加 `解决方案.md`、`操作手册.md`
